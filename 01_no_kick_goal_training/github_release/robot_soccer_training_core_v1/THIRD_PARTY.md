# Third-party runtime dependencies

This package depends on NVIDIA Isaac Lab / Isaac Sim, RSL-RL, PyTorch, and the
Unitree Go2 asset/configuration distributed with the Isaac ecosystem. Those
projects retain their own licenses and are not relicensed here.

The repository owner should select a project license and confirm that any
copied task configuration may be redistributed before making this directory a
public release. No model checkpoint is included.
